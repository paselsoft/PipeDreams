# Glossario di Pipe Dreams

Un nome per ogni cosa. Le skill `revisione-ux` e `storie-utente` leggono e aggiornano questo
file.

## Voce

Chiara, amichevole, breve. Si dà del tu. I comandi Unix restano in inglese e in `codice`.

## Termini

| Termine | Significa | Non dire |
| --- | --- | --- |
| Cella | Un posto della pipeline in cui si mette un comando | slot (solo nel contatore «Slot») |
| Pipeline | La catena di comandi delle celle | catena, programma |
| Input | Le righe che il programma scrive nella pipe | stdin (va bene nel manuale) |
| stdout atteso | Il risultato da ottenere | target, obiettivo |
| Par | Il numero minimo di comandi della soluzione | minimo, record |
| Stelle | Il voto di un livello, da ★ a ★★★ | punti |
| Aiuto | Un gradino di aiuto: spinta, piano, una cella | suggerimento (per il pulsante) |
| Atto | Un gruppo di livelli della campagna con la sua storia | capitolo, mondo |
| Sfida del giorno | Un livello generato, uguale per tutti, ogni giorno | daily |
| Maratona | Livelli generati contro il tempo | sfida a tempo |
| Allenamento | Livelli generati su un comando scelto | pratica, esercizio |
| Laboratorio | Una pipeline libera con il risultato dopo ogni comando | sandbox |
| Galleria | I livelli della community | community (solo nel titolo) |
| Caso | Un giallo a puntate | storia, missione |
| Capitolo | Una puntata di un caso | episodio, livello |
| Enigma | Una pipeline dentro un capitolo | livello, puzzle |
| Indizio | Il risultato di un enigma, salvato nel taccuino | prova, risultato |
| Taccuino | L'elenco degli indizi di un caso | note, diario |
| Deduzione | La domanda a fine capitolo | quiz (è un'altra cosa) |
| Quiz | Un livello «cosa stampa questa pipeline?» | domanda |
