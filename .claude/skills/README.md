# Skill di Pipe Dreams

Skill di progetto per Claude Code: si caricano da sole nelle sessioni su questo repository.
Il metodo (storie con criteri verificabili, una storia per commit, revisione UX prima del
codice, check-in di architettura, registro dei bug) è adattato da
[BAMA: Build Any Mac App](https://github.com/daveebbelaar/bama) di Dave Ebbelaar, pensato
per app macOS in Swift; qui è riscritto per un gioco web in JavaScript senza dipendenze.

| Skill | Quando |
| --- | --- |
| `pipedreams` | Non sai da dove partire: sceglie la skill giusta (solo su richiesta, `/pipedreams`) |
| `verifica` | Prima di dire «fatto»: sintassi, verifiche con bash, test nel browser, impaginazione |
| `storie-utente` | Una nuova funzione grande: backlog in `docs/STORIES.md` con criteri verificabili |
| `ciclo-miglioramento` | «Vai avanti», «lavora sul backlog»: una storia per commit fino a fine milestone |
| `revisione-ux` | Prima di scrivere una schermata, un'azione o dei testi; o per rivedere una schermata |
| `check-architettura` | Fine milestone, file oltre 1.000 righe, bug che si ripetono nella stessa zona |
| `nuovo-caso` | Scrivere un nuovo caso a puntate (o capitoli nuovi) |

Documenti condivisi: `docs/GLOSSARIO.md` (un nome per ogni cosa), `docs/FIXLOG.md`
(ogni bug con la sua regola).
