📖 MINI-MANUALE UNIX

grep -v 'X'

Scarta le righe contenenti X.

grep 'X'

Tiene solo le righe contenenti X (distingue maiuscole/minuscole).

sort

Riordina alfabeticamente (le maiuscole vengono prima). Con -r in ordine inverso.

uniq

Rimuove duplicati adiacenti.

head -n N / tail -n N

Tiene le prime / ultime N righe.

wc -l

Conta le righe del flusso.

cut -d':' -f2

Divide ogni riga sul delimitatore e tiene il campo indicato.

tr 'a' 'b' / tr -d 'a'

Sostituisce o elimina caratteri; con '\n' spezza le righe.

uniq -c

Come uniq, ma antepone quante volte si ripeteva ogni riga.

sort -n / sort -rn

Ordina per valore numerico (crescente / decrescente).

2>/dev/null

Cestina lo stderr del comando a cui è attaccato.

2>&1

Unisce lo stderr allo stdout, così gli errori entrano nella pipe.

|

Passa solo lo stdout al comando successivo: lo stderr va dritto al terminale.

sed 's/.*/\U&/'

Converti tutto in maiuscolo.
